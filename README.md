# Бот проверки реестра казахстанских товаропроизводителей (e-ondiris.gov.kz)

Telegram-бот [@ondiris95bot](https://t.me/ondiris95bot) следит за [Реестром КТП](https://e-ondiris.gov.kz)
и сообщает, когда организация из списка пользователя в нём появляется. Проверка идёт в 09:00 и 18:00 по Астане.

Ботом может пользоваться любой человек, и у каждого свой список БИН. Уведомление приходит всем, кто отслеживает этот БИН,
и содержит данные из реестра: компанию, регистрационный номер, дату включения и товары с ДВЦ и мощностью.

Данные берутся из открытого API реестра: `https://e-ondiris.gov.kz/awp-api/registry-front?bin_iin=<БИН>`.

## Команды бота

- Любое сообщение с БИН добавляет их в ваш список. Формат любой: столбиком, через запятую, из Excel, с названиями или без,
  либо файлом .txt/.csv. Если организация уже есть в реестре, бот сразу пришлёт её данные.
- `/list` — ваш список (✅ в реестре, ⏳ ещё нет)
- `/remove БИН БИН …` — удалить из списка
- `/help` — подсказка

Сообщения обрабатываются раз в час и перед каждой проверкой реестра.

## Устройство

- `inbox.py` — обработка сообщений боту (ежечасно, `.github/workflows/inbox.yml`).
- `check.py` — проверка реестра и рассылка уведомлений (`.github/workflows/check.yml`).
- `state.json` — списки пользователей и найденные организации. Бот сам обновляет его коммитами.
- Единственный секрет — `TELEGRAM_BOT_TOKEN`.
- Ручной запуск: Actions → «Проверка реестра» → *Run workflow*. С галочкой `debug` ответы API сохраняются в ветку `debug`.
- GitHub может запускать задания по расписанию с задержкой 5–30 минут.
