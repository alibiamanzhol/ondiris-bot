# Бот проверки реестра казахстанских товаропроизводителей (e-ondiris.gov.kz)

Бот запускается два раза в день, в 09:00 и 18:00 по Астане. Он проверяет, появились ли БИН из `bins.txt`
в [Реестре КТП](https://e-ondiris.gov.kz), и при появлении присылает уведомление в Telegram со списком товаров компании.
О каждом БИН бот сообщает один раз, найденные сохраняются в `state.json`.

Данные берутся из открытого API реестра, которым пользуется сам сайт: `https://e-ondiris.gov.kz/awp-api/registry-front?bin_iin=<БИН>`.

## Настройка

1. Создайте бота в [@BotFather](https://t.me/BotFather) (`/newbot`) и получите токен.
2. Добавьте секрет `TELEGRAM_BOT_TOKEN`: Settings → Secrets and variables → Actions → *New repository secret*.
3. Напишите боту `/start`. Первый, кто напишет, станет владельцем: уведомления будут приходить ему,
   а сообщения от остальных бот будет игнорировать. Чтобы сменить владельца, удалите `owner_chat_id` из `state.json`
   или задайте секрет `TELEGRAM_CHAT_ID`.
4. Отправьте боту список БИН (см. ниже) или впишите их в `bins.txt`.

## Пополнение списка через Telegram

Отправьте боту список БИН в любом виде: столбиком, через запятую, скопированный из Excel, с названиями или без,
либо файлом .txt/.csv. Бот вытащит из сообщения все 12-значные номера, пропустит повторы и предупредит,
если у БИН не сходится контрольная цифра.

- `/list` — текущий список (✅ уже в реестре, ⏳ ещё нет)
- `/remove БИН БИН …` — удалить
- `/help` — подсказка

Сообщения обрабатываются раз в час и перед каждой проверкой реестра, поэтому ответ приходит в течение часа.

## Прочее

- Ручной запуск: Actions → «Проверка реестра» → *Run workflow*. С галочкой `debug` сырые ответы API
  сохраняются в ветку `debug`.
- GitHub может запускать задания по расписанию с задержкой 5–30 минут.
- Чтобы бот снова проверил БИН, который уже был найден, удалите его запись из `state.json`.
