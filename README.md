# Бот проверки реестра товаропроизводителей (e-ondiris.gov.kz)

Бот запускается два раза в день, в 09:00 и 18:00 по Астане. Он проверяет, появились ли БИН из `bins.txt` в реестре,
и при появлении присылает уведомление в Telegram. О каждом БИН бот сообщает один раз, найденные сохраняются в `state.json`.

## Настройка

1. **Создайте Telegram-бота.** Напишите [@BotFather](https://t.me/BotFather), выполните `/newbot` и получите токен.
   Затем напишите своему боту любое сообщение и откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`: в ответе найдите `"chat":{"id": ...}`, это и есть chat_id.
   Для группы добавьте бота в группу; её id начинается с `-100`.
2. **Создайте приватный репозиторий на GitHub** и загрузите туда эти файлы.
3. **Добавьте секреты:** Settings → Secrets and variables → Actions → *New repository secret*:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. **Заполните `bins.txt`**, по одному БИН на строку. Название после БИН указывать необязательно.
5. **Сделайте тестовый запуск:** Actions → «Проверка реестра» → *Run workflow*, отметьте `debug`.
   Скриншоты страниц появятся в артефакте `debug`.

## Пополнение списка через Telegram

Отправьте боту список БИН в любом виде: столбиком, через запятую, скопированный из Excel, с названиями или без,
либо файлом .txt/.csv. Бот вытащит из сообщения все 12-значные номера, пропустит повторы и предупредит,
если у БИН не сходится контрольная цифра.

- `/list` — текущий список (✅ уже в реестре, ⏳ ещё нет)
- `/remove БИН БИН …` — удалить
- `/help` — подсказка

Сообщения обрабатываются раз в час и перед каждой проверкой реестра, поэтому ответ приходит в течение часа.
Бот принимает сообщения только из чата `TELEGRAM_CHAT_ID`.

## Подстройка под сайт

Поиск выполняется через браузер: бот открывает `REGISTRY_URL`, вводит БИН в поле поиска и ищет его в строках результатов.
Если по скриншотам видно, что бот попадает не туда, задайте переменные
(Settings → Secrets and variables → Actions → вкладка *Variables*):

| Переменная | Что это | По умолчанию |
|---|---|---|
| `REGISTRY_URL` | Прямая ссылка на страницу публичного реестра с поиском | `https://e-ondiris.gov.kz` |
| `SEARCH_SELECTOR` | CSS-селектор поля поиска | первое текстовое поле / поле с «БИН» или «поиск» |
| `RESULT_SELECTOR` | CSS-селектор строк результатов | `table tbody tr, [role=row], .ant-table-row` |

## Важно

- Сайты `*.gov.kz` иногда блокируют зарубежные IP, а серверы GitHub находятся за рубежом. Если при запуске
  приходит «⚠️ Ошибки при проверке» с таймаутами, запускайте бота на сервере или ПК в Казахстане:
  `pip install -r requirements.txt && playwright install chromium`, затем добавьте `python check.py` в cron
  (`0 9,18 * * *`) или в Планировщик задач Windows, а токен и chat_id передайте через переменные окружения.
- GitHub может запускать задания по расписанию с задержкой 5–30 минут.
- Чтобы бот снова проверил БИН, который уже был найден, удалите его запись из `state.json`.
